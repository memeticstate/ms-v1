Access and token

Premium Field Operator

Premium gives qualifying holders a deeper research workspace for indexed PONS V2 launches. Open the Premium tab on Memetic State, or select Open full research from a token's evidence view.

Access: 0.1%

Hold at least 0.1% of the fixed supply reference in your verified primary wallet on Robinhood Chain, chain ID 4663. The token contract is:

0xedf1ac25ff0cf741a9ee1490c630e3a4ecfbd4fc

Sign in through Privy and link the wallet that holds the tokens. The server verifies your linked wallet and checks its balance against independent RPC providers at the same block. Entering an address alone does not establish ownership, and balances from multiple wallets are not combined.

The first successful holder verification records the supply reference and its block. That denominator stays fixed for this gate; later burns do not silently reduce the required balance. The exact required token amount and reference block are shown with the access result. The public access configuration exposes the recorded reference once initialized.

Access checks are cached for up to two minutes. An open premium workspace attempts to renew verification before expiry; if verification cannot continue, the workspace locks. New premium requests are rechecked after expiry. Selling below the threshold can end access at the next check. If verification is unavailable, premium content remains locked and you can retry. A token mint or a future policy change would require an explicitly updated access policy rather than an undisclosed moving denominator.

How to use it

  1. Connect a wallet and select Recheck access if necessary.
  2. Open Premium, choose an indexed token, or paste its contract.
  3. Open the research dossier and check its coverage label first.
  4. Compare the three windows and read what would invalidate the interpretation.
  5. Follow source transactions or use Older indexed records to continue through the available history.
  6. Open Case files, add a thesis and an observable invalidation condition, and save the open window. Choose specific events or attach the first 20 available records on that page.
  7. Reopen the case later, select Compare latest evidence, and record your assessment. A newer read may still be historical if collection is delayed.

Research content is returned only after the server verifies holder access. It is not included as hidden data in the public page. The public field guide, overview, and basic evidence remain available for orientation.

A worked research example

Start with a question: Is participation becoming broader and lasting across observations? This is a research question, not a prediction of price.

  1. Select a token and 25,000 blocks, leave the ending block blank, then select Open research. Write down the evidence date. If the archive is delayed, this tests that historical period.
  2. Compare distinct actor counts and buy/sell records across the three windows. More addresses alone do not establish more independent people; related wallets can create apparent breadth.
  3. Read Cross-source ecology to see which assets share the same quote contract and which holder or registry observations are available. Check each source's date. A shared quote asset or habitat label does not establish correlation or endorse the token.
  4. Use a prompt to write a specific thesis, such as: “Participation broadened across the indexed windows and I want to see whether it persists.” Write a condition before the next observation: “Reconsider if actor counts fall across the next comparable windows, activity becomes concentrated, or the evidence is too stale to assess.”
  5. Choose Save this window as a case, attach useful source events, and save the thesis and invalidation condition. Return later and select Compare latest evidence. Save edited notes before comparing.
  6. Record Supported, Invalidated, or leave the case Open based on what the evidence can establish. If the index has not advanced, the new read is not a new market observation. Missing evidence leaves the question unresolved.

For a fresh discovery check, use the public factory feed, paste the token contract into Premium, and select Check recent curve. This works once the factory has discovered the contract, even if its historical dossier is not available yet. Read the exact block interval and times, then follow the source transactions. Zero returned curve trades only describes that curve and window; the token may be trading elsewhere after graduation.

The recent check and the saved case answer different time-based questions. Its counts stay separate from the archive's comparable windows, rankings, and original case evidence. You can record your own dated follow-up note and transaction reference in a case, but the recent check is not automatically attached as a saved snapshot.

What can follow

Additional venue integrations, richer retained-holder histories, expanded alerts, exports, and APIs can be added as their data and operating costs are established. Existing public or account tools keep their own access rules; they are not automatically an unlimited premium entitlement.

Funding and changes

Holding for access does not itself pay a recurring fee. The proposed creator-fee operating budget can help fund data, hosting, and development. Included features and access conditions can evolve through published changes; premium does not promise returns or permanent service regardless of funding.
