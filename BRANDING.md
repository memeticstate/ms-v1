# Memetic State — current branding

The current logo is the compass mark: four amber survey corners, sage horizontal and vertical axes, amber diagonal spokes, a cream center, two rose/rust endpoint circles, and a dotted rust quarter-circle between the north and east endpoints.

The former curved-path / squiggle / Porous State mark is retired in every palette. Do not reuse it, recolor it, reconstruct it from old conversations, or restore its earlier exports.

## Visual rules

Use warm near-black #15140F, cream #EDE6D5, amber #C9A227, sage #8FA876, rust #C1583A, and rose #C97B63. The UI SVG uses #C36A4B for its compact endpoint/arc ink. Preserve the vector geometry and the current raster reference when inserting the logo into artwork. A palette change never makes the retired curved-path mark current.

Use bold uppercase sans-serif for MEMETIC and a rust italic editorial serif for State. Do not substitute the former cyan/purple/navy branding. Keep clear space and avoid glow or glossy effects.
